## 🚀 Featured Project — **Framely – Mega DevOps AKS Platform**

A **production-style DevOps & GitOps platform implementation on Kubernetes (AKS)** using **cloud-agnostic DevOps practices with Terraform, Jenkins, and Argo CD**, re-architecting an existing application into a cloud-native delivery model.

### 🔑 Platform Highlights

- Architected a delivery model with **clear separation of CI, CD, and infrastructure responsibilities**
- **Jenkins** used strictly for Continuous Integration  
- **Git** as the single source of truth for environment state  
- **Argo CD** for GitOps-driven Continuous Delivery  
- **Terraform-based Infrastructure as Code** for AKS, networking, registry, and monitoring  
- **Kustomize-based environment promotion (stage → prod via Git)**  
- Integrated **Prometheus + Grafana observability stack**
- Fully reproducible locally using **Docker Compose, KIND, Jenkins, and Argo CD**

📂 Repository  
[Framely Mega DevOps AKS](https://github.com/MrSharma151/framely-mega-devops-aks-project)
